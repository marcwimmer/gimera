CI: Der Workflow laesst sich jetzt manuell starten (`workflow_dispatch`, Button „Run workflow" im Actions-Tab bzw. `gh workflow run CI --ref main`). Hilfreich, wenn ein Push-Event verloren geht — etwa waehrend einer GitHub-Actions-Stoerung — und bisher nur ein leerer Commit als Ersatz-Trigger blieb. Der Release-Job bleibt absichtlich an `push` gebunden und laeuft bei manuellem Start nicht mit.
